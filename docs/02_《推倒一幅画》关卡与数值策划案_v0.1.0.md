## 1. 关卡设计总目标与首发版本边界

本策划案为《推倒一幅画》**连续单线关卡体系与全盘数值的单一事实来源**，服务于手工精调、离线程序化生成（`tools/generate-levels.mjs`）以及上线后的关卡热更调优。

* **首版（`v1.0.0`）内容边界**：聚焦 **`1～20` 关**，全部由**基础三牌（普通牌 / 转向牌 / 分岔牌）**构成，包含 `4` 组完整「易 → 易 → 中 → 难 → 爽」波浪心流，单关网格 `5×6～10×10`、推力 `1～3`，快速完成微信小游戏上架与核心留存/变现验证。
* **后续版本（`v1.1+`）扩关路线**：自第 `21` 关起随版本更新渐进解锁重骨牌、弹簧牌、彩色闸门、桥牌、定时牌等 5 类进阶机关（详见 §3.2），本文同步锁定其数值边界以保证架构前向兼容。
* **核心原则**：
  1. **解压优先、思考托底**：所有关卡必须体现「推一下、倒一片」的连锁爽感，思考点集中在「推哪块 × 往哪推 × 先推谁」。
  2. **求解器兜底、拒绝无效关卡**：每关上线前必须通过离线求解器严格证明 `limit` 推可解且 `limit - 1` 推无解。
  3. **数值零付费墙**：不设体力、不设限时倒计时、撤销永久免费。

## 2. 关卡难度量化模型（四档精确定义）

系统用 **5 个可由求解器离线计算的量化指标** 定义关卡真实难度：

| 指标代号 | 指标名称 | 计算定义 | 玩家体感映射 |
| :---: | :--- | :--- | :--- |
| **`L`** | **最少推力** | 求解器证明的最小通关推数（首版 `1～3`，后续扩关 `1～5`） | 决策步数与整体思考跨度 |
| **`O`** | **顺序依赖度** | 将标准解 `sol` 的 `L` 推任意重排（`L!` 种顺序），因「已倒即挡」导致失败的排列占比（`0%～100%`） | 是否需要仔细判断「先推谁、后推谁」 |
| **`S`** | **首推容错率** | 棋盘全部合法首推中，存在后续 `L - 1` 推通关解的起手占比 | 找到「关键第一推」的直觉难度 |
| **`P_spec`** | **特殊牌占比** | `(转向牌 + 分岔牌 + 进阶机关) / 有效骨牌总数` | 棋盘视觉复杂度与路线分支密度 |
| **`C_max` / `C_min`** | **最大 / 最小单推覆盖率** | 标准解中单推倒下块数占总骨牌数的最高 / 最低比例 | 连锁爽感峰值与收尾饱满度 |

### 2.1 四档难度量化标准表（供生成器筛选）

| 难度档位 | 心流定位 | 推力 `L`（首版 / 后续） | 顺序依赖 `O` | 首推容错 `S` | 特殊牌占比 `P_spec` | 单推覆盖约束 | 预期单局时长 |
| :---: | :--- | :---: | :---: | :---: | :---: | :--- | :---: |
| **易** | 顺手破局、快速建立节奏 | `1～2` / `2～3` | `0%～20%` | `≥ 12%` | `10%～22%` | `C_min ≥ 18%` | `25～50 秒` |
| **中** | 看清路线、1～2 次撤销过关 | `2～3` / `3～4` | `20%～55%` | `5%～15%` | `15%～26%` | 常规 `C_min ≥ 15%` | `1～2 分钟` |
| **难** | 明确「已倒即挡」博弈，有破局成就感 | `3` / `3～5` | `≥ 50%` | `1%～8%` | `18%～30%` | 常规 `C_min ≥ 15%`（异形 `≥ 10%`） | `2～4 分钟` |
| **爽（逢 5 关）** | 大连锁倾泻、音阶拉满的奖励关 | `1～2` / `1～2` | `≤ 20%` | `≥ 15%` | `16%～28%`（高分岔） | **`C_max ≥ 60%`** 且链深 `≥ 12` 层 | `20～45 秒` |

> [!NOTE]
> 对「爽」关额外要求**最长单推 BFS 链深 ≥ 12 层**，确保加速间隔从 `130ms` 顺滑压低至 `42ms` 并将 G 调五声音阶完整拉升至高音区，配合 `≥ 40` 连击触发「超级连锁！」与牌桌震动。

### 3.3 进阶机关双混编允许矩阵（`v1.5+` / 131 关起生效）

遵循 `01` §4.2「单关进阶机关种数 `≤ 2`」铁律：

| 机关组合 | 是否允许 | 化学反应与限制说明 |
| :--- | :---: | :--- |
| **重骨牌 + 弹簧牌** | ✅ 推荐 | 弹簧折返补上第 2 撞，极易做出高爽感「一推破重甲」 |
| **重骨牌 + 桥牌** | ✅ 允许 | 跨区越过已倒区补第 2 撞；单关重骨牌 `≤ 4` 块、桥牌 `≤ 2` 块 |
| **重骨牌 + 彩色闸门** | ✅ 允许 | 闸门色块中可混入 1 块重骨牌提高先后手层次 |
| **弹簧牌 + 桥牌** | ⚠️ 慎用 | 必须通过生成器防死环校验（严禁弹簧对射或经桥牌形成封闭死循环） |
| **彩色闸门 + 桥牌** | ✅ 推荐 | 闸门后藏桥牌通道，路线反转惊喜感强 |
| **定时牌 + 重骨牌 / 桥牌** | ✅ 允许 | 仅在 `131+` 关「难」关位使用，每关定时牌 `≤ 2` 块（延迟 `N ∈ {1, 2}`） |
| **定时牌 + 弹簧牌** | ❌ 禁止 | 往返叠延迟导致心算负担过重，违背解压定位 |
| **定时牌 + 彩色闸门** | ❌ 禁止 | 延时开门时序过于隐蔽，易产生挫败感 |

### 5.2 像素画入库 5 条可玩性红线（入生成器前自动拦截）
1. **零孤岛原则**：像素画中禁止出现四邻域全为空位的 1 格孤立像素；全图正交连通分量数量必须 `≤ 目标推力 L`（爽关强制要求全图单连通分量）。
2. **有效填充率**：有效像素格数占外接矩形 `W × H` 的 **`45%～85%`**（环形画如第 17 关甜甜圈中空部分除外，外圈需保持 ≥ 2 格厚度）。
3. **色彩克制与聚片**：统一使用 [06_像素画与骨牌渲染实现方案](06_《推倒一幅画》像素画与骨牌渲染实现方案_v0.1.0.md) §2.2 的十色调色板，单幅画使用 `2～5` 种颜色；同色像素成片聚合。
4. **窄颈上限**：1 格宽且长度 `≥ 3` 的细长臂单幅画不超过 `2` 处。
5. **合规原创**：全部采用通用生活意象，严禁绘制受版权保护的第三方动漫/商标 IP 形象，画名控制在 `2～4` 个中文常用字。

## 6. 程序化关卡生成参数与求解器策略

衔接 [04_技术架构与开发手册](04_《推倒一幅画》技术架构与开发手册_v0.1.0.md) §5，离线生成器按以下数值参数批量生产并自动分级：

### 6.1 牌型生成决策权重表
当正向模拟连锁踏入尚未定型的格子 `(y, x)`（前方空闲=`f`，左/右空闲=`l`/`r`）时，按以下权重决定牌型：

| 邻格空闲态势 | 易 / 爽关权重 | 中 / 难关权重 | 说明 |
| :--- | :--- | :--- | :--- |
| **`f` 空闲，且 `l` 与 `r` 均空闲** | 分岔 `16%` / 转向 `12%` / 普通 `72%` | 分岔 `10%` / 转向 `18%` / 普通 `72%` | 爽关提高分岔率制造大面积开花 |
| **`f` 空闲，仅 `l` 或 `r` 之一空闲** | 转向 `14%` / 普通 `86%` | 转向 `20%` / 普通 `80%` | 适度拐弯避免全是直线 |
| **`f` 受阻，`l` 与 `r` 均空闲** | 分岔 `65%` / 转向 `35%` | 分岔 `50%` / 转向 `50%` | 撞墙自动引流，维持链路连贯 |
| **`f` 受阻，仅 `l` 或 `r` 之一空闲** | 转向空闲侧 `100%` | 转向空闲侧 `100%` | 沿画作边缘顺滑折返 |
| **三向均受阻** | 普通 `100%` | 普通 `100%` | 链路自然收尾 |

### 6.2 进阶机关注入配额上限（`v1.1+` 启用）

| 机关类型 | 单关数量建议 | 生成器注入与安全约束 |
| :--- | :---: | :--- |
| **重骨牌（`×2`）** | `1～5` 块 | 仅注入在「被标准解至少 2 条不同支路/推次经过」的交叉格上 |
| **弹簧牌** | `1～3` 块 | 仅放置在来向反方向仍有未倒骨牌的端点；禁止两块弹簧牌直接相对形成无限往返 |
| **彩色闸门** | `1～2` 组（每组 `1～2` 格） | 绑定颜色的像素总数占全图 `10%～25%`；求解器校验必存在合法前置开门推 |
| **桥牌** | `1～2` 块 | 放置于两推轨迹交叉点；单次连锁中同一桥牌最多被穿越 `4` 次，全局步数上限 `256` 防死环 |
| **定时牌** | `1～2` 块（`N ∈ {1, 2}`） | 仅用于消除两路在交叉点的时间竞争，按 `layer + N` 分桶确定性结算 |

### 6.3 最少推力证明与求解性能策略
1. **`v1.0.0` 全 20 关（`L ≤ 3`）**：标准 BFS 只需搜索深度 `1～2`，单关毫秒级完成 `L - 1` 无解紧界证明与全部难度指标（`O`、`S`）计算。
2. **`v1.1+` 高阶关（`L = 4～5`）**：深度 `3` 直接 BFS 去重（状态预算 `400,000`）；深度 `4`（`L = 5`）采用按倒下块数降序剪枝（忽略仅倒 1 块且不触发机关的微推，预算 `600,000`，单种子超时 `> 3s` 自动换种），确保 100% 严格证明。

## 7. 局内辅助与局外收集数值体系

广告点位与降级策略详见 [05_提审运营与商业化方案](05_《推倒一幅画》提审运营与商业化方案_v0.1.0.md) §2，本节定义具体数值：

### 7.1 局内辅助数值表

| 项目 | 基础额度 | 重置规则 | 激励视频补给上限 | 对「完美通关」影响 |
| :--- | :---: | :--- | :--- | :---: |
| **撤销（`↶`）** | 无限次 | — | 永久免费，无广告 | **无影响** |
| **重摆（`↺`）** | 无限次 | 重摆后**保留当前局剩余提示次数**（防刷提示） | 永久免费，无广告 | **无影响** |
| **提示（`💡`）** | 每关 `3` 次 | 切关或通关后再玩重置为 `3` 次；偏离标准解**不扣次数** | 归 `0` 后单次补 **`+2` 次**（单关限 `2` 次；第 `1～3` 关屏蔽） | 使用 `≥ 1` 次取消本关金框 |
| **额外推力（`+1`）** | `0`（仅失败面板） | 仅当前局有效；重摆不保留 | 单次获得 **`+1` 推力**（单关限 `2` 次；第 `1～3` 关屏蔽） | 使用 `≥ 1` 次取消本关金框 |

### 7.2 局外收集与皮肤 / 音色解锁阶梯（适配 `v1.0.0` 20 关完整闭环）

所有局外奖励均为**纯外观或纯听觉体验，零数值加成**：

| 收集系统 | 触发口径 | `v1.0.0`（20 关）解锁阶梯 | `v1.1+` 扩关追加阶梯 |
| :--- | :--- | :--- | :--- |
| **画廊图鉴点亮** | 每通关 1 关 | `1 ～ 20` 关逐幅点亮 | 随新关持续向后延展 |
| **画廊拼贴里程碑** | 累计通关数 | **通关全部 `20` 关**解锁「首版 20 画全家福拼贴海报」+ 金边相框 | 之后每满 `20` 关（`40 / 60 / 80 …`）解锁一套新拼贴海报 |
| **完美通关金框** | 单局 0 提示 + 0 额外推力通关 | 每关独立记录（`0～20` 枚，支持重玩补拿） | 随关卡增加上限同步提高 |
| **骨牌皮肤 & 音色包** | 累计完美金框数（外加默认「暖木绿呢」1 套） | **`5` 金框**：原木马林巴<br>**`12` 金框**：八音盒水晶<br>**`18` 金框**：竹筒风铃 | **`35` 金框**：麻将玉石<br>**`60` 金框**：糖果软胶<br>**`90` 金框**：星空钢琴 |
| **连锁纪录徽章** | 单推最长连倒数 | `×20` / `×40` / `×60`（第 15 关单推 66 连即可解锁全部 3 枚） | `×80` / `×100`（`12×12` 大关开放） |

## 8. 线上关卡健康度指标与动态调优红线

通过 `wx.reportEvent` 监控每关核心指标，触发红线即替换关卡种子热更调优：

| 难度档位 | 目标首通率 | 平均尝试轮次（重开+失败） | 提示使用率参考 | 触发降难 / 替换红线 |
| :--- | :---: | :---: | :---: | :--- |
| **第 1～3 关（新手）** | `≥ 92%` | `≤ 1.2` 次 | `< 8%` | 首通率 `< 85%` 或退出率 `> 8%` 立即调优 |
| **易** | `80%～92%` | `1.1～1.6` 次 | `5%～15%` | 首通率 `< 72%` |
| **中** | `60%～78%` | `1.6～2.8` 次 | `15%～30%` | 首通率 `< 50%` 或平均尝试 `> 3.8` 次 |
| **难** | `38%～58%` | `2.5～4.2` 次 | `25%～45%` | 首通率 `< 28%` 或单关流失率 `> 12%` |
| **爽（逢 5 关）** | `≥ 88%` | `≤ 1.3` 次 | `< 10%` | 首通率 `< 80%` 或最长连击未达标 |
