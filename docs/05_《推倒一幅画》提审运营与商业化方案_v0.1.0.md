## 1. 商业化定位与分阶段策略

### 1.1 首版定位：纯 IAA（广告变现）、零内购、轻装快跑
* **核心模式**：`v1.0.0`（首发 `20` 关）采用 **100% 纯 IAA 广告变现 + 本地单机存档**，不设任何虚拟货币内购与付费订阅。该模式在微信小游戏平台**免游戏版号**，可大幅缩短上线周期并实现零服务端运维成本。
* **体验底线**：以「解压感与次日留存」优先于短期广告压榨——**零体力限制、零强制开屏插屏、零通关强制弹窗**；广告以**玩家主动触发的激励视频（Rewarded Video）**为主体（预计占总收入 `80%～85%`），辅以极低侵扰的**原生模板/底部 Banner 广告**（预计占 `15%～20%`）。
* **首版目标**：`v1.0.0` 仅投放 `20` 关，目标不是靠 20 关直接大规模买量变现，而是以最低成本跑通**提审上线 → 破 1000 UV 开通流量主 → 验证核心留存与激励视频渗透率**，验证达标后再进入 `v1.1+` 扩关与买量放大。

### 1.2 多端商业化差异预留
* **微信小游戏（首期唯一交付）**：纯 IAA（微信流量主激励视频 + 结算/画廊原生模板广告）。
* **小红书 / 抖音小游戏（后期移植）**：沿用同一套 IAA 广告点位，通过 `IPlatformAdapter.showRewardedAd()` 切换对应平台流量主。
* **Steam 桌面端（远期可选）**：买断制，开启 `FeatureFlags.isPremiumDesktop = true` 自动隐藏全部广告入口，提示补给与皮肤试用转为通关积分/免费解锁。

## 2. 全链路广告点位设计与防骚扰频控

### 2.1 广告位总览矩阵

| 编号 | 广告形态 | 触发位置与时机 | 玩家获得价值 | 频控与保护规则 | 预期贡献 |
| :---: | :--- | :--- | :--- | :--- | :---: |
| **A1** | **激励视频** | 失败面板「`+1` 额外推力」按钮（玩家主动点击） | 本关立即获得 **`+1` 点推力**，可继续推倒剩余骨牌 | 第 `1～3` 关不展示；单关上限 **`2` 次**；使用后本关取消完美金框 | 核心主力（~50%） |
| **A2** | **激励视频** | 局内工具栏 `提示` 次数归 `0` 后再次点击 | 本关立即补充 **`+2` 次提示** | 第 `1～3` 关不展示；单关上限 **`2` 次**；使用后本关取消完美金框 | 次主力（~25%） |
| **A3** | **激励视频** | 画廊/皮肤页点击未解锁皮肤或音色包的「免费试用」 | 免费体验该皮肤与音色包 **`3` 关** | 不影响完美金框与核心数值；单日上限 `3` 次 | 补充收入（~10%） |
| **B1** | **原生模板 / Banner** | 画廊浏览页底部、通关结算面板最底缘（可选灰度开启） | 无遮挡展示 | **严禁出现在对局棋盘进行中**；距最近可点按钮留白 `≥ 24px` 防误触 | 长尾补充（~15%） |

### 2.2 明确禁止的广告行为（体验与合规红线）
1. **禁止强制插屏**：任何通关、重摆、切关或进画廊动作不得强弹插屏广告。
2. **禁止虚假关闭与诱导误触**：不得伪造关闭按钮、不得延迟渲染广告导致玩家误点。
3. **禁止未完整观看发奖**：严格校验微信激励视频回调 `res && res.isEnded === true` 才发放 `+1` 推力 / `+2` 提示 / 皮肤试用；中途关闭仅 Toast 提示「完整观看视频后即可领取」。

### 2.3 冷启动无流量主与无填充降级方案
微信小游戏需**累计独立访客（UV）达到 1000 人**方可开通流量主并获取真实广告位 ID。因此客户端内置两级平滑降级机制：

| 运行态场景 | 开关状态 | 客户端表现（保证零报错、零死按钮） |
| :--- | :--- | :--- |
| **提审期 / 未开通流量主** | `FeatureFlags.adEnabled = false` | 隐藏所有广告角标；提示归 `0` 与失败面板 `+1` 推力降级为**每关免费赠送 `1` 次**（或纯提示「撤销/重摆」），确保审核员体验 100% 顺畅。 |
| **已开流量主但偶发无填充 / 网络异常** | `onError` 触发 | 弹出友好 Toast「暂无可播放视频，请稍后再试」，不扣任何次数、不锁死界面；若单局连续拉取失败 `2` 次，弹出免费应急 `1` 次提示/推力兜底，避免负向流失。 |

## 3. 首版 20 关数据测算与验证门槛

### 3.1 `v1.0.0`（20 关）用户消耗与变现估算
* **单用户内容时长**：完整打通 `1～20` 关预计总时长 **25～40 分钟**，自然跨 **1～2 个活跃日**（加上补拿 18 个完美金框解锁全部 3 套首发皮肤，总可玩时长可达 **50～70 分钟**）。
* **激励视频需求分布**：
  * 第 `1～3` 关：零广告保护期；
  * 第 `4、8、9、13、14、18、19` 关（中/难关）：主要产生 **A1（`+1` 推力）**与 **A2（补提示）**需求；
  * 综合估算活跃用户日均有效视频观看 **`1.0～2.2` 次**，按微信休闲小游戏激励视频常规 eCPM `¥25～¥45` 计，ARPDAU 约 **`¥0.03～¥0.10`**。

### 3.2 启动 `v1.1.0`（扩关与进阶机关）的立项验证门槛
首版 `20` 关上线获取首批 `1,000～3,000` 自然/种子用户后，按以下门槛决策下一步投入：

| 核心验证指标 | 达标立项线（启动 v1.1 扩关） | 预警调优线（优先改手感/前 10 关） |
| :--- | :---: | :---: |
| **第 1 关通关率** | `≥ 94%` | `< 88%`（检查滑动引导与首推触发门槛） |
| **前 5 关累计完播率** | `≥ 68%` | `< 52%`（检查第 2～4 关难度坡度） |
| **次日留存（D1）** | `≥ 30%` | `< 20%`（复盘解压反馈与首日爽关节奏） |
| **20 关全通关率（活跃 2 日内）** | `≥ 25%` | `< 12%`（检查 14/19 难关是否过难） |
| **激励视频渗透率（开流量主后）** | `≥ 25%` | `< 15%`（评估提示免费次数是否给得过宽，如 `3 → 2`） |

## 4. 冷启动获客与合规社交裂变设计

为快速跨过 **1000 UV 流量主门槛**，利用本作「连锁解压视频极具观赏性」与「像素画天然适合炫耀」两大优势，设计 4 个零服务端成本的传播点：

1. **通关像素画卡片分享（合规自主分享）**：通关面板右上角提供轻巧「分享这幅画」按钮，离屏合成高清画作 + 战绩卡片（如「我 1 推连倒 66 块推倒了【彩虹云】，来试试你能几推？」），调用 `wx.shareAppMessage`。
2. **卡关好友求助卡片**：失败面板提供「发给好友出主意」次按钮（附当前关卡缩略图，好友点击卡片通过 `query` 参数直达同一关试玩）。
   > [!CAUTION]
   > **严格遵守微信防诱导分享规范**：严禁设置「分享到群即可立即复活/获得推力/获得提示」，严禁强迫分享或拦截未分享回调；一切分享均为纯自愿社交互动。
3. **20 关毕业「全家福拼贴海报」**：通关全部 `20` 关弹出专属毕业礼花页，离屏生成 `4×5` 的 20 幅像素画高清拼贴图（附个人总推数、最高单推连击与完美金框数），支持一键保存到相册发朋友圈 / 小红书。
4. **短视频挂载自然引流（视频号 / 小红书 / 抖音）**：直接录制第 10 关 `热气球`、第 15 关 `彩虹云`（单推 66 连清屏）与第 20 关 `大皇冠` 的 `10～15 秒` 纯享倒牌 + 五声音阶升调实机视频，挂载小游戏卡片获取免费精准解压用户。

## 5. 全通关 20 关优雅承接与运营活动预留

`v1.0.0` 仅含 `20` 关，玩家打通第 `20` 关（大皇冠）后**严禁出现白屏、循环卡死或无反馈按钮**，需配置完整的终关承接闭环：

1. **毕业庆典弹窗**：展示「🎉 已推倒首版全部 20 幅画！」与 20 画拼贴海报预览，引导一键保存分享。
2. **两大长尾回流目标**：
   * **补齐 20 枚完美金框**：明确展示当前进度（如 `完美金框 14/20`），一键跳转至尚未拿到金框的关卡重玩解锁剩余皮肤与音色包；
   * **刷新最高连击纪录**：支持在画廊中自由重玩任意已通关画作（特别是第 5 / 10 / 15 / 20 关大连锁爽关）。
3. **新关预告占位**：画廊末尾置放「更多画作与重骨牌新机关即将上线」预告卡，降低核心玩家卸载率。

## 6. 微信小游戏提审、资质与合规自检清单

### 6.1 前置资质准备（纯 IAA 无内购路径）

| 资质项 | 是否必需 | 说明与周期预估 |
| :--- | :---: | :--- |
| **微信小游戏账号（AppID）** | 必需 | 个人主体即可注册并开通纯 IAA 流量主；若计划后续投放微信广告买量或上多端，建议优先企业主体。 |
| **工信部小程序/小游戏 ICP 备案** | 必需 | 微信公众平台后台提交，约 `3～15` 个工作日，未备案无法发布上线。 |
| **计算机软件著作权 / 自审自查报告** | 按主体要求 | 纯单机无内购小游戏免版号；按微信小游戏当前最新类目资质指引提交软著或电子版权登记证书及《游戏自审自查报告》。 |
| **微信隐私保护指引** | 必需 | 后台声明仅使用本地存储保存游戏进度与设置，不收集手机号、位置、通讯录等敏感信息。 |

### 6.2 提审前 10 项必过自检红线

| 序号 | 检查项 | 验收标准 |
| :---: | :--- | :--- |
| **C01** | **健康游戏忠告 & 适龄提示** | 启动加载页完整展示《健康游戏忠告》；首屏/设置页按规范展示 `CADPA 8+` 绿色适龄提示图标及点击说明弹层。 |
| **C02** | **右上角胶囊安全区避让** | 在 iPhone 刘海屏/灵动岛与主流安卓全面屏真机实测，顶栏任何可点按钮与微信 `[••• \| ⊙]` 胶囊无重叠。 |
| **C03** | **主包体积与静态扫描** | `npm run verify:wx` 通过：主包 `≤ 4 MB`（本作约 `120～180 KB`），零 `eval` / `new Function` / 未备案外链请求。 |
| **C04** | **像素画原创无侵权** | 首版 20 幅像素画均为通用生活意象（小花、小猫、小房子、彩虹云等），不出现任何第三方动漫、影视、商标 IP 形象。 |
| **C05** | **零诱导分享与零强制广告** | 提审包默认 `adEnabled = false`（未开流量主前）；全流程无「分享才给过关/道具」字样与逻辑。 |
| **C06** | **音频与震动生命周期合规** | 切后台（`onHide`）及来电中断立即暂停音频，回前台（`onShow`）恢复；提供全局一键静音且持久化。 |
| **C07** | **20 关全通无报错** | 从第 1 关一路通到第 20 关及毕业承接页，控制台 0 未捕获异常，重进小游戏进度与金框准确恢复。 |
| **C08** | **画廊重玩与撤销/提示边界** | 覆盖 [01_核心玩法策划案](01_《推倒一幅画》核心玩法策划案_v0.1.0.md) §8 全部 `E01～E10` 边界用例，低端机稳跑 60 FPS。 |
| **C09** | **文案与图标规范** | 无错别字、无占位英文/调试文字（如 `TODO`、`test`），无外部平台导流字样。 |
| **C10** | **客服与反馈入口** | 设置页提供简洁的版本号显示与平台原生反馈入口，便于快速定位线上异常。 |

## 7. 轻量埋点方案（零服务端直连 `wx.reportEvent`）

首版不搭自建数据后台，全部复用微信小游戏后台内置自定义分析 `wx.reportEvent(eventId, data)`：

| 事件名 | 触发时机 | 上报关键字段 | 核心分析用途 |
| :--- | :--- | :--- | :--- |
| `level_start` | 进入任意关卡开局 | `level_id`, `is_replay` | 计算关卡到达率与留存漏斗 |
| `push_executed` | 完成一次推牌连锁 | `level_id`, `push_idx`, `chain_size` | 验证单推连锁爽感与覆盖率是否符合预期 |
| `level_action` | 点击撤销 / 提示 / 重摆 | `level_id`, `action_type`, `hints_left` | 定位卡点关卡与提示消耗分布 |
| `level_fail` | 推力耗尽弹出失败面板 | `level_id`, `remaining_tiles`, `extra_used` | 统计失败率与触发热更降难红线 |
| `level_win` | 全部推倒通关 | `level_id`, `pushes_used`, `best_chain`, `is_perfect`, `duration_sec` | 计算首通率、金框率、单局时长与完播漏斗 |
| `ad_event` | 激励视频点击 / 拉取成功 / 完整看完 / 失败 | `slot_id` (`A1`/`A2`/`A3`), `stage`, `level_id` | 计算广告渗透率、完播率与无填充降级频次 |
| `share_event` | 点击通关分享 / 求助 / 毕业海报保存 | `scene`, `level_id` | 评估自然裂变效率 |
| `skin_equip` | 解锁或切换骨牌皮肤 / 音色包 | `skin_id`, `source` (`gold_frame`/`ad_trial`) | 评估长线收集激励效果 |
