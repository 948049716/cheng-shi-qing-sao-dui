# 《推倒一幅画》

微信 / 小红书轻量小游戏立项策划与设计文档仓库。

核心玩法为**竖屏单指多米诺连锁推倒像素画**：按住一块骨牌朝指定方向轻滑，借助转向牌、分岔牌与「已倒即挡」规则规划路线与顺序，在最少推力内连锁推倒整幅像素画。
